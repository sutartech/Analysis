🚀 Implementation & Setup Guide

Step 1: GitHub Setup
Create repo indian-stock-analysis, add folder /data/stocks.json, push this DC as index.html
Step 2: Google Apps Script
Visit script.google.com, create project, add function to fetch stock data from APIs every 5 mins
Step 3: GitHub Token
Generate personal access token in GitHub Settings → Developer settings, add to Apps Script for API writes
Step 4: Data Sources
Use NSE India API, yfinance, Rapid API, or Alpha Vantage (free tiers available)
Step 5: Auto-Schedule
In Google Apps Script, set trigger: fetchStockData every 5 minutes
Step 6: Deploy
Enable GitHub Pages, deploy from root, live at yourusername.github.io/indian-stock-analysis
