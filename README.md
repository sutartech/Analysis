## 🐛 Troubleshooting

**Data not updating?**
- Check Google Apps Script → Executions
- Verify GitHub token is valid
- Check trigger is scheduled

**Website not loading?**
- Wait 5 mins after first deploy
- Clear browser cache
- Verify repo is public

**Stock prices wrong?**
- NSE API sometimes delayed 15 mins
- Check timestamp in data
- Fall back to static data if needed
